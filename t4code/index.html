everything in this build

regions
Every pane is a tile: right dock (browser, files, agents, review) concurrent with the transcript and the bottom terminal. Per-session layouts persist.
floating
Any tile pops out into its own floating panel on macOS — and docks back with one click.
settings
Full OMP settings from the app: models per agent role, thinking level, approval mode, provider keys (masked), wss pinning, theme. Writes are confirmed and revision-checked.
fork
Branch any session into a full-history copy — rail row menu, session menu, or the TUI (f).
design mode
Annotate an element in the browser pane, add a note, and a structured prompt lands in the composer.
gallery
The files pane shows real image thumbnails with a full-screen preview.
unread
Accent dots on rail rows with new activity; ⌘⌥U cycles unread sessions on macOS.
unread
Terminal mouse reporting — htop, vim, lazygit take clicks and scrolls.
wss
Pinned TLS alongside plain ws on the tailnet — TOFU fingerprint in the Keychain, published on /healthz.
preview
Host-side headless-Chromium preview service: launch, navigate, capture, click/type/scroll, leases — all 22 commands.
t4 tui
The whole product in a terminal: rail, live transcript, composer, fork — one self-contained binary.
